# ProofPilot release smoke-test checklist

**Status:** Manual checklist prepared; this checklist has not been executed as part of Sprint 3.

- [ ] Open the deployed application URL.
- [ ] Enter the assessment without authentication; confirm no OTP screen or redirect blocks access.
- [ ] Start the Data Analyst declining-retail-sales scenario.
- [ ] Open the supplied dataset, schema, and data dictionary.
- [ ] Execute a valid SQL query in the workspace.
- [ ] Confirm the displayed rows are the query's actual results.
- [ ] Complete the analysis tasks and navigate between steps.
- [ ] Submit evidence-based findings and business recommendations.
- [ ] Submit the assessment and generate the report.
- [ ] Refresh, then reopen the saved report in the same browser profile.
- [ ] Confirm the report discloses client-side deterministic scoring, browser-local persistence, and lack of independent verification.
- [ ] Check that the workspace and report are usable at a typical laptop desktop size.
